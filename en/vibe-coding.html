October 9–11, 2026 · Hyangnam real estate office

Updating listings in bulk for a Hyangnam brokerage

I built a bulk update tool for my mother’s brokerage so staff could reuse listings from Real Estate Bank on the office website.

The tool matches each row in the export to a listing on the website by its ID and highlights what has changed. Staff can review several listings on one screen and choose which fields to update.

I verified the maintenance fees for 65 listings against the source records. I also compiled separate reference fees for 20 floor-area types across nine apartment complexes so staff could look them up when adding a property.

October 14–19, 2026 · Hanbit Trading accounting lab

From source documents to the general ledger

I built an accounting lab using transactions from Hanbit Trading, a fictional wholesaler. In the first exercise, learners examine the documents for a sale and decide which accounts to use.

I connected Codex and Claude Code to the same ledger through a shared Model Context Protocol (MCP) server. Either client can retrieve the transaction and its supporting documents. The chat explains the choice of account, while a TypeScript accounting engine prepares the entry and calculates the amounts.

Journal entries stay in draft until a learner approves them. Posting an approved entry updates the general ledger and trial balance, so learners can trace one transaction from the original documents to the books.

October 24–31, 2026 · Japanese vocabulary

A JLPT vocabulary app with personal review lists and Chiikawa characters

I built a web app to review 7,180 vocabulary items across JLPT levels N5 through N1. It saves my word-by-word progress in the browser, so I can return to just the words I marked as unfamiliar.

I worked with Codex to give six Chiikawa characters distinct behavior during study sessions. The app uses a different set of weighted actions for each character. Hachiware might play guitar, while Usagi might jump.
