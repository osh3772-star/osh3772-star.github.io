2026.10.09–11 · 향남 중개사무소

관리비 70건을 하나씩 복사해야 할까?

어머니의 중개사무소 홈페이지에 부동산뱅크 매물을 옮기다가 관리비에서 막혔습니다. 상세 화면에 관리비가 적혀 있어도 목록에는 0원으로 나오는 매물이 있었습니다. 이대로라면 관리비 70건을 하나씩 열어 복사해야 했습니다.

가져온 표와 홈페이지에 저장된 값을 나란히 놓고 바꿀 칸만 고르게 했습니다. 표에 빈칸이나 0원이 들어와도 기존 관리비를 지우지 않게 했습니다. 10월 11일에는 매물별 관리비 65건을 저장한 뒤 다시 조회해 입력값과 일치하는지 확인했습니다.

배운 점 표에 적힌 0원만으로는 관리비가 무료인지 알 수 없었습니다. 개별 매물에서 확인한 금액과 같은 면적에서 참고할 금액도 따로 저장했습니다.

2026.10.18–19 · 한빛유통 회계 학습실

한빛유통 장부로 매출 한 건을 분개하기

수업에서 배운 분개가 실제 장부에 어떤 기록으로 남는지 따라가고 싶었습니다. 가상회사의 미처리 매출을 한 건 골라 증빙을 읽고 전표를 검토하는 회계 학습실을 만들었습니다.

Codex와 Claude Code가 같은 회계 기능을 쓰도록 MCP 서버를 연결했습니다. 대화창에서 거래와 증빙을 조회하면 회계 엔진이 분개 초안을 만듭니다. 웹에서는 증빙과 차변·대변을 대조하고 전표를 승인해 원장에 반영하는 과정을 연습합니다.

배운 점 거래를 읽는 일과 장부에 올리는 일에는 다른 절차가 필요했습니다. 조회는 대화창에서 하고, 원장에는 사람이 승인한 버전의 전표만 반영하도록 했습니다.

한빛유통 회계 학습실 열기

2026.10.24–31 · 일본어 단어장

단어를 외우는 화면에 치이카와를 넣고 싶었습니다

JLPT를 준비하면서 제가 모르는 단어만 모아 다시 풀고 싶었습니다. N5부터 N1까지 급수를 고르고, 단어를 볼 때마다 ‘알고 있음’과 ‘모르겠음’을 표시하는 단어장을 만들었습니다. 복습할 때는 표시해 둔 단어부터 이어서 볼 수 있습니다.

공부하는 화면에는 제가 좋아하는 치이카와 캐릭터를 넣었습니다. 우사기와 하치와레의 대표 장면을 찾아보고, 성격에 맞는 행동이 서로 다른 확률로 나오게 했습니다. 하치와레는 기타를 치고 우사기는 주먹밥을 먹기도 합니다.

배운 점 처음 보는 단어를 고르는 기준은 급수였지만, 복습할 때는 내가 어떤 단어를 몰랐는지가 더 중요했습니다. 그래서 브라우저에 단어별 표시를 저장하고 ‘모르는 단어’만 모아 보는 화면을 따로 두었습니다.
