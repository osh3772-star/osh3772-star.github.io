2026.10.09–11 · 乡南（Hyangnam）房产中介门店

乡南中介门店的房源批量更新工具

为了减少母亲的房产中介门店在两个网站上重复录入房源的工作，我开发了房源批量更新工具。

导入韩国房源平台“房地产银行”（부동산뱅크）导出的表格后，工具按房源编号匹配门店网站上已有的记录，并标出有变化的项目。经办人可以在同一页面核对多套房源，再选择需要更新的项目。

我用原始资料核对了 65 套房源的物业管理费，还为 9 个小区的 20 种面积类型单独整理了参考金额，供登记新房源时查阅。

2026.10.14–19 · Hanbit 会计实训平台

在 Hanbit 平台上从原始凭证练到过账

我用虚构批发企业 Hanbit 的交易资料搭建了会计实训平台。第一项练习从一笔销售开始，学习者先核对原始凭证，再判断应使用的会计科目。

我通过同一个 MCP 服务将 Codex 和 Claude Code 接入同一套账。学习者可以在任一应用中查询交易和凭据，讨论科目选择的依据。分录生成和金额计算由 TypeScript 会计引擎完成。

待审核的记账凭证以草稿保存。学习者在网页上批准并过账后，就能在总账和试算平衡表中查看这笔交易，核对原始凭证、分录和账簿之间的对应关系。

JLPT 词汇本的复习记录与角色动作
