2026.10.09–11 · 향남 중개사무소

관리비 70건을 하나씩 복사해야 할까?

어머니의 중개사무소 홈페이지에 부동산뱅크 매물을 옮기다가 관리비에서 막혔습니다. 상세 화면에 관리비가 적혀 있어도 목록에는 0원으로 나오는 매물이 있었습니다. 이대로라면 관리비 70건을 하나씩 열어 복사해야 했습니다.

가져온 표와 홈페이지에 저장된 값을 나란히 놓고 바꿀 칸만 고르게 했습니다. 표에 빈칸이나 0원이 들어와도 기존 관리비를 지우지 않게 했습니다. 10월 11일에는 매물별 관리비 65건을 저장한 뒤 다시 조회해 입력값과 일치하는지 확인했습니다.

배운 점 표에 적힌 0원만으로는 관리비가 무료인지 알 수 없었습니다. 개별 매물에서 확인한 금액과 같은 면적에서 참고할 금액도 따로 저장했습니다.

2026.10.18–19 · 한빛유통 회계 학습실

AI가 읽은 장부와 내가 연 장부가 같을까?

가상회사 한빛유통에서 아직 처리하지 않은 매출 한 건을 골라 분개를 연습하고 싶었습니다. Codex와 Claude Code가 같은 회계 도구를 쓰도록 MCP 서버를 연결했습니다. 그런데 웹을 새로고침해도 승인 목록에는 아무것도 보이지 않았습니다. 대화창에서 제가 보고 있는 장부를 열었는지부터 확인했습니다.

18일에는 테스트 환경에서 회계 도구 41개를 불러왔습니다. 다음 날 제가 쓰는 Codex 대화에서 연결 상태와 회사 정보를 차례로 조회했습니다. 응답에 담긴 회사 ID가 웹 장부 상단의 ID와 같았습니다. 웹의 조회 기록에서도 방금 보낸 요청을 찾았습니다.

배운 점 어느 장부를 읽었는지는 회사 ID와 조회 기록으로 확인할 수 있었습니다. 전표를 승인하고 원장에 반영하는 과정은 별도 테스트 장부에서 확인했습니다.

10월 19일 연결 검증 기록

2026.10.24–31 · 일본어 단어장

단어를 외우는 화면에 치이카와를 넣고 싶었습니다

JLPT 단어를 공부하는 화면에 제가 좋아하는 치이카와 캐릭터를 넣고 싶었습니다. 우사기부터 하치와레, 치이카와 순으로 대표 장면을 찾아보고, 캐릭터마다 어떤 자세와 표정이 어울리는지 하나씩 정리해 달라고 했습니다.

성격이 다른 캐릭터들이 저마다 다른 행동을 하도록 확률을 두자고 했습니다. 단어장은 캐릭터별 표에서 행동을 하나 뽑습니다. 하치와레의 행동에는 기타 연주가, 우사기의 행동에는 주먹밥 먹기가 있습니다. 캐릭터를 조작하는 동안에는 방향키를 눌러도 단어 답변이 바뀌지 않게 했습니다.

작업 중 고친 점 ‘모르는 단어’에서 N4를 골라도 다른 화면에 다녀오면 선택이 풀렸습니다. 단어 목록과 복습 화면의 급수를 따로 저장하도록 고쳤습니다. 화면을 오가는 모의 검사로 수정 결과를 확인했습니다.
